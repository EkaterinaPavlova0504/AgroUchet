# АгроУчет — Информационная система фермерского хозяйства

## Описание проекта

АгроУчет — это информационная система для автоматизации производственного и хозяйственного учёта в фермерском хозяйстве. Система предназначена для сельскохозяйственных предприятий, желающих оптимизировать учёт полей, животных, кормов и удобрений, а также автоматизировать расчёт себестоимости продукции и формирование отчётности для государственных органов.

## Функциональность

- Учёт полей и посевных культур (регистрация полей, севооборот, фиксация посева и уборки)
- Учёт животных (приём, привесы, надои, перемещение, ветеринарные события)
- Учёт кормов и удобрений (приход на склад, остатки, списание по группам)
- Расчёт себестоимости продукции (молоко, мясо, зерно)
- Формирование отчётности для Минсельхоза и пакета документов на субсидии
- Управление пользователями и ролями (агроном, животновод, бухгалтер, руководитель)

## Структура репозитория

| Ветка | Описание |
